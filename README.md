# Jamf API Utility

An app to simplify the creation of admin API scripts and promote good secret security. 

Starting with v0.8.0 the application will submit basic hardware, OS, and API Utility application usage to [TelemetryDeck](https://telemetrydeck.com). The data is sent anamously and used to aid in the development of the application. To opt out of data the sending of data click 'Opt out of analytics' in the applications About window.

Please find a User's Guide in the Wiki section of this project.
